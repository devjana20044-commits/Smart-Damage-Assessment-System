# ✅ قائمة اختبارات التكامل (Integration Testing Checklist)

> **تاريخ الإنشاء:** 2026-04-11
> **الهدف:** ضمان عمل التكامل بين Flutter و Laravel بشكل صحيح

## 🔧 متطلبات ما قبل الاختبار

### إعداد الباك إند:
- [ ] تشغيل Laravel: `php artisan serve --host=0.0.0.0`
- [ ] تشغيل migrations: `php artisan migrate:fresh --seed`
- [ ] تشغيل Queue Worker (لاختبار AI): `php artisan queue:work`
- [ ] إنشاء Storage Link: `php artisan storage:link`
- [ ] التأكد من وجود GEMINI_API_KEY في `.env`

### إعداد الفرونت إند:
- [ ] تحديث IP الخادم في شاشة Settings أو `config.dart`
- [ ] تشغيل `flutter pub get`
- [ ] توصيل جهاز أو محاكي
